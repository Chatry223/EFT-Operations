EFT OPERATIONS / EconomyGuard 1.9.1
=====================================

هدف نسخه‌ها:
- EFT: 0.16.1.3.35392-P2P
- SPT: 3.11.1
- Fika Server: 2.4.3
- Fika Client: 1.2.3

نصب سمت سرور
-------------
1) SPT Server را خاموش کن.
2) از user/profiles، user/mods/SPT-EconomyGuard و پوشه مستقل SPT-EconomyGuard-Data در ریشه SPT بکاپ بگیر.
3) بسته سرور EFT Operations را در ریشه SPT استخراج کن؛ مسیر نهایی مود باید user/mods/SPT-EconomyGuard باشد.
4) پوشه SPT-EconomyGuard-Data در ریشه SPT نگهداری می‌شود؛ آن را داخل user/mods منتقل نکن و هنگام ارتقا حذف نکن.
5) سرور را اجرا کن و لاگ Startup و SPT-EconomyGuard-Data/health.json را بررسی کن.
6) پنل محلی: http://127.0.0.1:6970/
7) توکن پنل: SPT-EconomyGuard-Data/admin.token

امنیت
------
- پنل ادمین فقط روی 127.0.0.1 گوش می‌دهد؛ پورت 6970 را مستقیم به اینترنت باز نکن.
- برای مدیریت راه دور از VPN مدیریتی یا Reverse Proxy امن همراه احراز هویت استفاده کن.
- قبل از فعال‌کردن Require approved account، حساب مدیر را Approve کن.
- ثبت‌نام عادی لانچر بسته است؛ حساب‌های جدید را از پنل بساز.
- IP Allowlist فقط درخواست‌های HTTP به SPT را کنترل می‌کند و به‌تنهایی UDP ترافیک Fika را فایروال نمی‌کند.
- در این Build، انتقال آیتم Fika از مسیر Item Sending توسط EconomyGuard Hook نشده است. برای بستن آن مسیر، allowItemSending را در fika.jsonc غیرفعال نگه دار.
- Ban ورود و Backend HTTP را می‌بندد؛ Kick فوری بازیکن از Raid فعال P2P تضمین نشده است.

پنل و Status Site
-----------------
- پنل ادمین: http://127.0.0.1:6970/
- سایت وضعیت عمومی: http://IP-سرور:1234/ (TCP 1234 را فقط در صورت نیاز باز کن).
- تنظیم Status Site، اعلان‌ها، پس‌زمینه و بخش‌های قابل نمایش از پنل ادمین انجام می‌شود.
- IP نشان‌داده‌شده در پنل، آخرین IP درخواست HTTP SPT است و لزوماً IP مسیر UDP بازیکن نیست.

سیستم مأموریت EFT Operations
----------------------------
1) از پنل ادمین وارد بخش Operations شو.
2) مأموریت را با نقشه، نوع Solo/Squad، ظرفیت، Briefing، Objectiveها و پاداش بساز.
3) Draft را ذخیره و پس از بررسی Publish کن.
4) بازیکنان از افزونه کلاینت مأموریت را قبول و Ready می‌شوند.
5) Adapter نسخه Fika Server 2.4.3 گروه را فقط وقتی به Match متصل می‌کند که همه اعضای لازم Ready و در همان Match/Map باشند.
6) پایان Match گروه را به صف بررسی مدیر منتقل می‌کند.
7) پس از تأیید مدیر، امتیاز Rank ثبت و تحویل روبل/آیتم از طریق Mail سرویس SPT انجام می‌شود.

محدودیت مهم Objective:
- اتصال کامل رویدادهای Kill / Loot / Visit / Extract به موتور پیشرفت هنوز تکمیل نشده است.
- داده‌های Raid End از کلاینت قابل جعل‌اند و به‌تنهایی مجوز پرداخت جایزه نیستند.
- HUD فعلی عنوان و هدف‌ها را نمایش می‌دهد، اما شمارنده Objective را به‌صورت زنده و معتبر به‌روزرسانی نمی‌کند.
- تا تکمیل و تست منبع رویدادهای معتبر، تصمیم نهایی و پرداخت جایزه باید با بررسی مدیر باشد.

ساخت افزونه کلاینت
------------------
1) در ویندوز، Visual Studio با MSBuild و .NET Framework 4.7.2 targeting pack لازم است.
2) فایل source/EFT-Operations-1.9.1/client/EFT.Operations.Client/BUILD-GUI.bat را اجرا کن.
3) در GUI روی Load bundled ZIPs بزن تا Referenceهای هدف از آرشیوهای منبع استخراج شوند.
4) مسیر واقعی نصب BepInEx را در فیلد سوم انتخاب کن؛ این مسیر باید پوشه‌ای باشد که داخلش core و plugins وجود دارد.
5) Build and Install DLL را بزن.
6) خروجی در BepInEx/plugins/EFTOperations نصب می‌شود؛ DLL قبلی Backup و build-report.txt تولید می‌شود.
7) بازی را از SPT Launcher اجرا کن و داخل بازی F8 را بزن.

نسخه‌ها با SHA-256 کنترل می‌شوند: EFT Assembly-CSharp، Fika.Core 1.2.3.0 و spt-common 3.11.1.0. فایل‌های بازی فقط ورودی Build هستند و نباید داخل بسته قابل نصب مود قرار بگیرند.
