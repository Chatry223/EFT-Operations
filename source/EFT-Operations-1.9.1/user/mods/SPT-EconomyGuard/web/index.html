Local-only by default

The admin API binds to 127.0.0.1 and requires a random token. Do not expose this HTTP port directly to the internet.

ssh -L 6970:127.0.0.1:6970 admin@SERVER

Then open http://127.0.0.1:6970 on your computer. The tunnel keeps the panel private.
